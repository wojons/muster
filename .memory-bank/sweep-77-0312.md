**Code Comparison**:

Spec approach:
```go
type MigrationManager struct {
    db        *sql.DB
    tableName string
}

func (mm *MigrationManager) applyMigration(m Migration) error {
    tx, err := mm.db.Begin()
    if _, err := tx.Exec(m.Up); err != nil {
        return fmt.Errorf("up migration failed: %w", err)
    }
    _, err = tx.Exec(
        "INSERT INTO schema_migrations (version, applied_at, name) VALUES (?, ?, ?)",
        m.Version, time.Now(), m.Name,
    )
    return tx.Commit()
}
```

Actual approach (better):
```go
type MigrationManager struct {
    db      *sql.DB
    log     *zap.Logger
    dir     string
    dialect string
}

func (mm *MigrationManager) Up() error {
    if err := goose.Up(mm.db, mm.dir); err != nil {
        return fmt.Errorf("run migrations: %w", err)
    }
    return nil
}
```

**Why Goose is Better**:

- ✅ Up/Down/Status commands built-in
