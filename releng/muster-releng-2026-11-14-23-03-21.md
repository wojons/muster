## Next action

The only gate this lane cannot clear itself is **owner authorization** (criterion 4). When the
owner records go-ahead on RELEASE-014, and one commit exists whose four workflow runs are all
terminal success and whose Docker leg is green, the cut is a mechanical sequence:

```
make release VERSION=v0.2.0          # or goreleaser release --clean
git tag -a v0.2.0 -m "muster v0.2.0" <green-sha>
git push origin v0.2.0
gh release create v0.2.0 --notes-file <categorized-notes> dist/*.tar.gz dist/checksums.txt
```

Tags `v0.1.0` and `v0.1.1` must never be moved. If a cut is attempted and fails, delete only a
freshly created tag with owner consent — never force-move an existing one.
