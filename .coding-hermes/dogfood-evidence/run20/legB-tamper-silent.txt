== B0 audit command surface as documented ==
View audit log events recorded by the CLI, daemon, and MCP server.

Events are persisted as JSON lines in the audit log file.

Usage:
  openapi-cli audit [command]

Available Commands:
  info        Show audit configuration and statistics
  log         Show recent audit events (optionally filtered)
  show        Show recent audit events
  status      Show audit logging status

Flags:
  -h, --help   help for audit

Global Flags:
      --profile string   Configuration profile to use (overrides MUSTER_PROFILE and the persisted default)

Use "openapi-cli audit [command] --help" for more information about a command.
